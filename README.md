# Test Automation Framework [UI-Trello, API - тетовый полигон PFLb]( https://trello.com, "http://82.142.167.37:4879/") 
___
## О проекте
Автоматизированный фреймворк для тестирования платформы Trello, тестового полигона PFLb 
<br> Проект включает в себя UI тесты для Trello, API тесты для тестового полигона PFLb.
___
## Технологический стек
* Java
* Maven
* TestNG
* Lombok
* Selenide
* Allure
___
## UI тесты
### HomeTest
```
1. Проверка открытия главной страницы

2. Проверка наличия вкладок главной страницы

3. Проверка всплывающего окна вкладок главной страницы

Проверка вкладок (кликабельность): 
4. - Features;
5. - Solutions;
6. - Plans;
7. - Resources;

8. Проверка кликабельности элемента Pricing

9. Проверка подложки в поле для email

10. Проверка кликабельности кнопки SignUp

11. Проверка кликабельности точек-кнопок и отображение зависимостей

12. Проверка hover эффекта бело-синих кнопок

13. Проверка кликабельности синих кнопок:
    - Browse Integrations;
    - Get to know Automation;
    - Compare plans.
```
### LoginTest
```
1. Проверка открытия страницы авторизации 

2. Проверка сообщения пустого email (авторизация негативный сценарий)

3. Проверка сообщения некорректного email (авторизация негативный сценарий)

4. Проверка чекбокса Запомнить меня (функция “Remember Me”)

5. Проверка наличия кнопок авторизации

6. Проверка работы ссылки восстановления пароля (функции “Forgot Password”)

7. Проверка авторизации (положительный сценарий)
```
## API тесты
### CarTest
```
1. Тест создания нового автомобиля через API

2. Тест получения данных об автомобиле

3. Тест обновления данных автомобиля

4. Тест удаления автомобиля
```
### HomeTest
```
1. Создание нового дома с жильцами и парковочными местами

2. Получение информации о созданном доме

3. Обновление информации о доме

4. Удаление дома по ID
```
### UserTest
```
1. Создание нового пользователя с проверкой в БД

2. Получение данных пользователя по ID

3. Обновление данных пользователя

4. Обновление данных пользователя
```
___
## Запуск тестов
### Для запуска тестов используйте:
``` mvn clean test ```

## Генерация отчетов
### Отчеты генерируются через Allure:
``` mvn allure:serve ```

## Интеграция с CI/CD
*Проект интегрирован с GitHub Actions для автоматического запуска тестов и генерации отчетов..*
